# Pièces du dossier — versions Markdown

Ce dossier contient, pour chaque pièce du projet d'élevage de veaux de la **SAS DU MOYER**
(Le Moyer, Verrie), deux fichiers :

- **`…-brute.md`** : le **texte intégral** de la pièce, obtenu par reconnaissance optique
  (OCR) des PDF scannés. **Aucune correction ni interprétation** — des erreurs de
  reconnaissance (mots collés, accents, chiffres, pages inversées) sont possibles.
- **`…-resume.md`** : un **résumé rédigé par IA** à partir de ce texte.

Les PDF d'origine sont dans `../pieces/`. La page publique qui réunit tout est `../dossier.md`.

| Dossier 3 — Aptitude des sols à l'épandage | `dossier-3-brute.md` | `dossier-3-resume.md` |
| Dossier 4 — Plans de situation | `dossier-4-brute.md` | `dossier-4-resume.md` |
